# 豚说配色

以官方扁平稿为准，3D 毛绒版沿用同色系。

| Token | 用途 | 参考 |
|---|---|---|
| Dolphin Blue | 头套、身体主色、徽章底 | 天蓝约 `#6FCFF9`，可略提亮或略灰，不要变深蓝或紫色 |
| Body White | 脸、胸腹白色弧形 | 干净白，不要偏黄 |
| Blush Pink | 腮红 | 软粉，面积小 |
| Logo White | φ 笔画 | 纯白，线条纤细手写感 |
| Avatar Orange | 推荐头像背景 | 暖橙，与天蓝强对比，缩小时醒目 |
| Soft Mint / Soft Blue | 可选场景背景 | 低饱和，不抢角色 |

禁止：高饱和霓虹、迷彩、金属拉丝、真实品牌色带。
