# 豚说角色锁定表

> 身份定位：豚豚是陪跑型吉祥物。它陪用户、团队和内容一起推进，承担当前主题里的一个关键动作；表情和姿态可以随主题变化，外貌识别锚点始终稳定。

## 参考图优先级

生成前优先读取并上传用户最新提供的参考图，路径为：`assets/references/`（本地副本，首次建立时来自桌面 IP 素材目录）。只阅读文件而不把它放进生图请求，不算使用参考图。

1. 最新 IP 参考图（若用户另行提供，以最新版本为准）
2. `三视图.png`：确认正面、侧面、背面外貌结构
3. `多表情图.png`：确认表情变化范围
4. `02-pose-wave.png` 至 `07-pose-hold-phone.png`：确认动作、比例和材质
5. 文字描述

生成任何豚说插图时，以下特征视为硬约束。可改变的只有姿态、道具、场景和情绪；生成器应在请求中收到至少一张实际参考图。

## 必须保留（外貌不可变）

- 主体：圆脑袋的小人，外面套着天蓝色海豚头套（不是真人海豚，是头套人设）。
- 头套：天蓝色哑光短绒；额头上方左右各一个圆点状小黑点，间距较宽，不是竖直长条；左上只有一个圆钝的小突起，不是尖的片状背鳍。
- 脸：头套开口内是大面积奶白色圆脸；两个黑色圆点眼；一个微笑小弧线嘴；淡粉圆形腮红。表情可变，但不改五官结构。
- 身体：**纯天蓝色，没有任何白色腹部或斜切色块**。白色 / 奶白色只出现在脸部和胸口徽章外层大圆盘。
- 徽章：胸口中央为**三层结构圆形徽章**——外层奶白色大圆盘，内层天蓝色圆，最中心白色粗笔手写花体 φ（顶部小卷、向下长笔画）。三层缺一不可，不要简化成「蓝底白 φ」，不要换成印刷体或其他字母。
- 四肢：短圆粗壮，手臂呈圆柱状、无明显手指，腿短而圆钝。
- 质感：细腻毛毡 / 麂皮短绒，表面平滑柔和，边缘有轻微绒毛轮廓；**不是蓬松长毛绒玩具**。柔和棚拍光，轻微体积阴影。
- 比例：头身比接近 1:1，整体矮胖圆润。

## 默认去掉

- 头套旁的水滴 / 喷水点缀（除非用户明确要求保留）。
- 墨镜、夹克、喇叭等个人配件（除非用户明确要求）。

## 可改

- 姿态：站立、挥手、摊手、抱物、坐、走、回头等。
- 道具：电脑、卡片、书本、咖啡杯等，与主题相关即可。
- 背景：纯色、渐变、简单场景；头像优先纯色。
- 情绪：开心、疑惑、专注、庆祝；用眉眼和肢体表达，不改五官结构。
- 动作：搭建、搬运、分拣、推开、修补、连接、带队、解释、观察、转化，或从配文提炼出的一个关键动作。
- 配饰：可按主题替换，不是角色身份锚点；可使用工具、手机、书、旗帜等，但不能遮住中央徽章。

## 禁止

- 扁平粗描边矢量风。
- 改成真实海豚、鱼、或其他动物。
- 改变主色（天蓝 + 奶白 + 粉腮红）。
- 添加白色腹部、蓝白斜切、猫耳、第二个背鳍或长条黑点。
- 改变头部、脸部、身体比例或中央三层徽章。
- 遮住或删除中央徽章 / φ 标（构图裁切时也要尽量保留）。

## 生成判断

- 外貌不可变，动作可变，水滴默认去掉，配饰可变。
- 豚豚每张图承担一个关键动作，不做无意义站立装饰。
- 表情服务于主题，但不改变五官结构。
