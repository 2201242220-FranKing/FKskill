# 豚豚参考图输入协议

## 目标

参考图必须进入生图请求本身。Agent 先读图只能帮助理解，不能替代给模型上传图像。

## 选图

- `三视图.png`：锁定头套、身体、比例和背面结构。
- `多表情图.png`：确认表情变化范围。
- `02-pose-wave.png` 至 `07-pose-hold-phone.png`：按目标动作选择最接近的一张。

如果生成器支持多张输入，可同时传一张身份结构图（优先三视图）和一张动作图；只支持一张时，选择与目标动作最接近的 pose 图，并在提示词里重复三层徽章与纯蓝身体约束。

## 请求要求

1. 将实际文件作为 `image1` / `input_image` / 工具对应的图像输入字段上传。
2. 如果接口支持 `input_fidelity`，设为 `high`；如果模型对图像输入已默认高保真，则不要传不支持的参数。
3. 提示词第一段只做身份锁定：保持参考图的头套、圆点黑点、单个圆钝突起、奶白脸、纯天蓝身体、三层徽章、比例和毛毡短绒材质。
4. 提示词第二段只改变动作、道具、背景、构图和情绪。
5. 生成器不接受图像输入时，不把最终结果当作合格图生图；应停下说明需要支持参考图的模式，或只交付提示词草稿。

## 生成后核验

逐项对照参考图：纯天蓝身体、三层徽章、两个宽间距圆点、单个圆钝突起、奶白脸、毛毡短绒。任一项错误，先重做提示词或更换参考图，不用更多装饰掩盖身份漂移。
