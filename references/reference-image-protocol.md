# 豚豚参考图输入协议

## 目标

参考图必须进入生图请求本身。Agent 先读图只能帮助理解，不能替代给模型上传图像。

## 生成前检查

每次生成前都要完成下面的检查；任一项不满足，就只交付提示词草稿，不生成或宣称完成了合格最终图。

1. **选对模型和工具**：确认当前生图工具支持图生图 / 参考图输入。纯文生图模型不能满足本 Skill 的角色一致性要求。
2. **选好参考图**：记录准备使用的真实文件名，并确认文件存在、可读取。
3. **检查实际调用参数**：查看当前工具的图像输入方式，把图片作为真实附件、图片数据或工具规定的图像字段传入。不同工具字段名不同，先核对工具说明，不要猜字段。
4. **确认图片确实随请求发送**：在调用参数或界面附件中确认至少有一张参考图。只在提示词里写文件路径、`image1`、`input_image` 或“参考图已上传”，都不算传入图片。
5. **保真参数按工具支持情况设置**：只有工具文档明确支持时才设置 `input_fidelity: high` 或等效参数；不支持或无法确认时省略。

## 选图

- `三视图.png`：锁定头套、身体、比例和背面结构。
- `多表情图.png`：确认表情变化范围。
- `02-pose-wave.png` 至 `07-pose-hold-phone.png`：按目标动作选择最接近的一张。

如果生成器支持多张输入，可同时传一张身份结构图（优先三视图）和一张动作图；只支持一张时，选择与目标动作最接近的 pose 图，并在提示词里重复三层徽章与纯蓝身体约束。

## 请求要求

1. 图片输入放在生图工具的实际调用参数或附件中；不要把本地路径当作图片输入。
2. WorkBuddy 使用 Agnes 图改图时，按已安装的 `agnes-image-2.0` Skill 调用 `agnes-image-2.0-flash`，将图片 URL 放入 `extra_body.image` 数组。仅在工具已有上传流程能生成服务可访问的 URL 时使用；不要把本地路径或 `file://` 地址冒充图片 URL。
3. 提示词第一段只做身份锁定：保持参考图的头套、圆点黑点、单个圆钝突起、奶白脸、纯天蓝身体、三层徽章、比例和毛毡短绒材质。
4. 提示词第二段只改变动作、道具、背景、构图和情绪。
5. 生成器不接受图像输入、当前模型是纯文生图、没有可用的图片上传方式，或无法确认请求是否带图时，停止最终出图；可以只交付提示词草稿，并说明需要切换到支持参考图的模式。

## 生成后核验

记录实际使用的参考图文件名和生图模型，并逐项对照参考图：纯天蓝身体、三层徽章、两个宽间距圆点、单个圆钝突起、奶白脸、毛毡短绒。任一项错误，先确认图像输入确实生效，再重做提示词或更换参考图，不用更多装饰掩盖身份漂移。
