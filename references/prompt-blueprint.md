# 豚说插图提示词蓝图

最终 `prompts/illustration.md` 必须按此结构写成**一整段可直接生图的提示词**。把角色圣经与配色改写进各节，不要另附「设定附录」。

```text
# 豚说插图提示词

你是资深潮玩 IP 视觉导演与 3D 角色设计师。

生成一张豚说官方 IP 插图。画幅：{generation_ratio}。用途：{use_case}。构图：{composition_id}。

## 输入

- 主题：{topic}
- 情绪：{mood}
- 道具：{props_or_none}
- 背景：{background}
- 标题文字（可空）：{title_text}
- 语言：{zh_or_en}
- 禁用元素：{banned}

## 角色（硬约束）

画一个圆脑袋小人，套着天蓝色毛茸茸海豚头套。头套前额有两个小黑点眼；左上有一小片背鳍；不要水滴。开口内是白色圆脸、小黑点眼、粉腮红。身体为天蓝短绒 + 胸腹白色弧形色块。胸口居中天蓝色椭圆徽章，内为白色手写 φ。全身细密毛绒质感，棚拍柔光，潮玩公仔体积感。

## 构图与场景

{composition_instructions}

角色必须清晰可读；头像类构图中头部与徽章落在中心安全区。

## 风格落地

- 3D 毛绒 / 潮玩，不要扁平描边，不要真人照片。
- 主色：天蓝 + 白 + 粉腮红；背景按用途选取（头像推荐暖橙）。
- 若有标题：少、大、可读，不遮挡脸与 φ 标。

## 禁用

扁平矢量风；改换海豚头套特征；删除或篡改 φ；默认墨镜；真实品牌/学校 Logo；杂乱小字；水滴（除非输入要求）。

## 完成标准

一眼能认出是豚说 IP；毛茸茸质感明确；缩小到头像尺寸仍可辨认头套轮廓与配色。
```

把 `{composition_instructions}` 写成具体镜头语言（景别、朝向、肢体、道具位置），不要只写构图 id。
