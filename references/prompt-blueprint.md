# 豚说插图提示词蓝图

最终 `prompts/illustration.md` 是一份可直接交给生图工具的融合提示词，由连续的两段组成：第一段锁定参考图身份，第二段只改变动作与场景。不要另附会冲突的角色设定附录。

调用生图工具前，Agent 在提示词之外完成这份记录；不要把记录当作图片提示词提交：

- 实际使用的参考图文件：{reference_image_filename}
- 当前生图工具 / 模型：{tool_and_model}
- 工具文档规定的图像输入字段或附件：{actual_image_input_method}
- 调用参数 / 附件中已确认包含这张参考图：是 / 否
- 如果不是“是”，停止最终出图；不要仅凭提示词里的文件名或文字宣称已上传。
- 只有工具文档明确支持时，才设置高图像保真度参数。

## 可提交给生图工具的提示词模板

```text
# 豚说插图提示词

你是资深潮玩 IP 视觉导演与 3D 角色设计师。

生成一张豚说官方 IP 插图。画幅：{generation_ratio}。用途：{use_case}。构图：{composition_id}。

## 主题输入

- 主题：{topic}
- 情绪：{mood}
- 道具：{props_or_none}
- 背景：{background}
- 标题文字（可空）：{title_text}
- 语言：{zh_or_en}
- 禁用元素：{banned}

## 第一段：严格保持参考图角色身份

严格保持输入参考图中的豚豚：圆脑袋小人、天蓝色海豚头套、额头两个间距较宽的圆点状黑点、左上单个圆钝小突起、奶白色圆脸、黑色圆点眼、微笑小弧线嘴和粉腮红。身体必须是纯天蓝色，不能出现白色腹部或蓝白斜切。胸口中央必须完整保留三层圆形徽章：奶白大圆盘、天蓝内圆、白色粗笔手写花体 φ，三层缺一不可。保持参考图的头身比例、短圆四肢和细腻毛毡 / 麂皮短绒材质，表面平滑柔和，不要蓬松长毛、猫耳、尖鳍、塑料皮肤或扁平矢量。

## 第二段：只改变动作与场景

只改变豚豚的{key_action}、{props_or_none}、{background}、{composition_instructions}和{mood}，让这个动作表达“{cognitive_anchor}”。保留完整中央徽章，默认去掉水滴，其他配饰只在服务主题时加入，不遮挡脸和徽章。标题若有，只放少量大字并留出安全区，不要大段正文、PPT 网格或商业海报模板。

## 禁用

白色腹部；蓝白斜切；三层徽章缺层；把圆钝突起画成猫耳或尖鳍；两个黑点变成长条或竖直排列；蓬松长毛；扁平矢量；真人照片；默认墨镜；默认水滴；真实品牌 / 学校 Logo；杂乱小字。

## 完成标准

生图请求的实际参数 / 附件确实包含参考图；记录所用文件名和模型；一眼能认出参考图中的豚豚；纯天蓝身体、三层徽章、两个宽间距圆点、单个圆钝突起、奶白脸和毛毡短绒均通过 QA；豚豚承担一个关键动作，画面只表达一个认知锚点。
```

把 `{composition_instructions}` 写成具体镜头语言（景别、朝向、肢体、道具位置），不要只写构图 id。若生成器不支持图像输入，只交付提示词草稿，不宣称已完成合格出图。
