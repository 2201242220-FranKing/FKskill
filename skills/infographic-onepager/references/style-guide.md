# 一图流风格指南与实例

## 风格变体库

同一套 6 层结构，背景和人物按用途切换：

| 用途 | 背景场景 | 人物/元素 | 主色建议 |
|------|---------|----------|---------|
| 团队培训/群发 | 职场办公/城市 | 卡通职场人、手机界面 | 蓝 |
| 校园/学生群体 | 校园建筑、草地、蓝天 | 卡通学长学姐、搜索框 | 蓝/绿 |
| 小红书封面 | 简约场景+大字留白 | 无人物或半身 | 按账号调性 |
| 直播预告 | 直播间/舞台感 | 主播形象、日历时间 | 橙/紫 |
| 销售SOP | 微信聊天场景感 | 聊天气泡、对话图标 | 绿 |

## 提示词四层结构（配图环节通用）

写任何生图提示词都按四层问清一张图：

1. **画什么**：图片用途 + 核心主体 + 主体细节
2. **怎么呈现**：场景 + 构图 + 光线
3. **一个主风格**：一次只保留一个，风格越多方向越乱
4. **限制条件**：3-5 条，只写最可能犯的错

把评价换成画面：
- "主体太小" → "主体放大到画面 70%"
- "背景太乱" → "删除多余装饰"
- "没地方放标题" → "主体移到左侧"
- "高级/精致/好看" → 删掉，换成可执行的画面描述

两个坑：风格只能选一个；限制别超过 5 条，超过画面会僵。

## 完整填充实例

主题：为什么要做自媒体

```text
主题标题：为什么要做自媒体
一句话定位：小红书 / 抖音不是额外工作，是销售的前置动作
核心公式：成交效率 = 搜索可见度 × 信任建立速度 ÷ 转化摩擦
核心逻辑：一条信任链：先被看见，再被相信，最后被咨询

步骤一：搜索占位
说明：客户会主动搜索相关攻略和问题。谁先被搜到，谁先进入视野。

步骤二：建立身份
说明：主页持续发专业内容、真实日常、答疑记录，从"卖东西的人"变成"靠谱的人"。

步骤三：私域承接
说明：内容里轻量引导私信，私聊再问需求、给方案，降低成交阻力。

方法论模块一：发什么
要点：干货攻略、避坑提醒、真实答疑、轻量转化。

方法论模块二：四条原则
要点：先价值后转化；先帮忙后成交；真人感大于精致感；每条内容留一个轻动作。

一句话总结：
谁先在目标客户心里建立"靠谱的人"的身份，谁后面成交就更轻松。
```
