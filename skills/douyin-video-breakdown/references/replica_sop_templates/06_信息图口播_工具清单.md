# 信息图口播_工具清单复刻SOP模板

## 适用场景

适合 AI 工具清单、开源项目合集、效率工具推荐、知识库方法论、学习路线和行业观察类短视频。

## 推荐工具链

- 脚本：Codex / ChatGPT / Claude
- 视觉：Figma / Canva / Keynote / PowerPoint / 即梦 / Midjourney
- 剪辑：剪映 / CapCut / Premiere
- 配音：真人口播 / TTS
- 字幕：自动字幕 + 人工校正英文工具名

## 标准复刻流程

1. 选择一个清单型主题，例如“10 个 Obsidian AI Skills”。
2. 写一句重定位钩子：不是 A，而是 B。
3. 列出 6-10 个条目，每个条目只保留一句“解决什么问题”。
4. 为封面和每个重点条目制作统一风格的信息图卡片。
5. 按“总观点 -> 问题 -> 清单 -> 新手建议 -> CTA”剪辑。
6. 给英文工具名、数字和关键词加大字强调。
7. 导出前人工校正字幕中的产品名、工具名和专有名词。

## 关键注意事项

- 不要把每个工具讲深，清单类视频的价值是结构化和可收藏。
- 视觉风格必须统一，避免每张卡片像不同来源。
- 结尾给低门槛入门组合，比单纯“记得收藏”更有行动价值。
