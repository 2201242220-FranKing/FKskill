# FKskill

参考 dbs 的“主入口路由 + 独立子技能”组织方式。主入口负责识别意图，具体任务由子技能执行。

## 路由表

| 用户需求 | 子技能 | 技术名 |
|---|---|---|
| 豚豚 IP 插画、正文配图、平台封面、海报、Banner、流程图、知识库与 AI 工具主题视觉设计 | Tun skill | `tun-skill` |

## 执行

- 明确的视觉需求：读取同级 `../tun-skill/SKILL.md` 并立即按其流程执行，保留用户原文、平台、尺寸和用途，不重复询问已提供的信息。
- 用户只输入 FKskill：简短说明当前可用 Tun skill，询问要制作什么图。
- 若平台已发现并安装 `tun-skill`，可直接调用；否则读取仓库内上述文件。安装不完整时指出需要安装的子目录，不假装已调用。
- 子技能中的资源路径均相对于该子技能目录解析，参考图必须真实进入生图请求。
- 多项同类视觉需求交给 Tun skill 统筹；超出插画与视觉设计（如网站开发、商业诊断）时说明当前没有对应子技能，不强行套用 Tun skill。
- 不复制角色、尺寸、字体规则到主入口；这些规则以 Tun skill 为准。新增技能时再更新本表，不预建空模块。
