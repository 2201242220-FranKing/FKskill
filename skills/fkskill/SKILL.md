# FKskill

个人技能工具箱入口：识别用户的具体任务，交给最匹配的子技能完成。主入口不代替子技能执行专业流程。

## 路由表

| 用户需求 | 子技能 | 技术名 |
|---|---|---|
| 豚豚 IP 插画、正文配图、平台封面、海报、Banner、流程图及视觉设计 | Tun skill | tun-skill |
| 为校园宠物设计可个性化的海豚系角色、头像、立绘、贴纸或主页形象 | 小海豚 IP 生成 | xiaohaitun-ip-generator |
| 方法论、SOP、培训内容的一图流或竖版信息图 | 方法论一图流生成器 | infographic-onepager |
| 从母稿改写为多个平台的文章、图文或脚本 | 多平台内容改写 | xiaojin-content-repurposer |
| 小红书账号定位、起号、选题、流量诊断与内容打磨 | 小红书起号教练 | xiaohongshu-launch-coach |
| 拆解单条短视频并整理报告、结构复刻 SOP | 短视频拆解复刻教练 | douyin-video-breakdown |
| 整理 Obsidian / Markdown 知识库、收件箱、索引或 MOC | 知识库自进化管家 | knowledge-base-evolver |

## 执行规则

- 明确的请求：若客户端已发现匹配的子技能，交由其执行；否则从本仓库对应 skills 子目录读取完整指引。缺少资源或脚本时说明需安装对应完整目录，不假装已调用。用户已提供的信息不重复询问。
- 用户明确点名某个子技能时，优先按该技能执行。
- “小红书封面”属于 Tun skill；“小红书起号/账号策略”属于小红书起号教练；多平台改写母稿走多平台内容改写。
- 豚说官方角色豚豚走 Tun skill；个性化校园宠物海豚角色走小海豚 IP 生成。
- 子技能的支持文档、脚本和素材均相对于该子技能目录解析。需要完整能力时须安装整个子技能目录。
- 用户只输入“FKskill”时，说明目前可用能力并询问要完成什么任务。
- 若请求不属于当前子技能范围，说明目前没有相应子技能，不强行套用其他流程。增加技能时同步维护本路由表和根目录说明。
