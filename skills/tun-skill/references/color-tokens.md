# 豚说配色与材质 Token

以 `assets/references/` 的最新参考图为准。颜色可以因光线轻微变化，但不得改变分区关系。

| Token | 用途 | 参考 |
|---|---|---|
| Dolphin Blue | 头套、身体主色、徽章内圆 | 柔和天蓝，允许轻微提亮或降饱和，不要变深蓝或紫色 |
| Cream Face | 脸部 | 奶白色，不能变成纯白面具或肤色 |
| Cream Badge Plate | 徽章外层大圆盘 | 奶白色，必须完整围住天蓝内圆 |
| Blush Pink | 腮红 | 软粉，面积小 |
| Logo White | φ 笔画 | 白色粗笔手写感，保持花体结构 |
| Felt Shadow | 阴影 | 柔和浅灰蓝，不要硬黑描边 |
| Soft Mint / Soft Blue | 可选场景背景 | 低饱和，不抢角色 |

## 身体分区硬规则

- 身体是纯天蓝色。
- 身体没有白色腹部、白色弧形色块或蓝白斜切。
- 奶白色只出现在脸部和徽章外层大圆盘。
- 徽章内圆是天蓝色，中心是白色粗笔手写 φ。

## 材质硬规则

使用细腻毛毡 / 麂皮短绒：表面平滑柔和、边缘只有轻微绒毛轮廓。禁止蓬松长毛、塑料亮面和金属材质。

禁止：高饱和霓虹、迷彩、金属拉丝、真实品牌色带。
