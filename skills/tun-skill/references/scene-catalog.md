# 用途与构图目录

先按平台与发布位置自动判断构图；只有关键歧义无法从上下文推断时，才推荐 2–3 项供选择。以下平台规则优先于后文无平台时的通用默认值。

## 平台、发布位置与画幅默认值

以下是制作时的常用画布建议，不代表平台永久或强制规格。用户给出的尺寸优先；平台上传界面可能裁切或更新，发布前以当前预览为准。先判断“平台 + 发布位置”，不要只按平台名套一个比例。

| 平台 | 发布位置 / 用途 | 默认画幅与像素画布 | 版式与风格适配 |
|---|---|---|---|
| 小红书 | 笔记封面、单张配图、轮播页 | 3:4，1080×1440 | 手机竖屏优先；缩略图中主体和短标题清楚，留出裁切安全边距。轮播组统一比例和视觉层级。 |
| 抖音 | 视频封面、竖屏视频配图 | 9:16，1080×1920 | 主体放在中间安全区，顶部和底部为平台界面留空间；轮廓鲜明、动作直接、对比清楚。 |
| 抖音 | 图文笔记、轮播页 | 3:4，1080×1440 | 使用竖版阅读顺序；减少小字，系列页统一边距、标题层级和配色。 |
| X | 信息流 / 长文正文插图 | 16:9，1200×675 | 编辑插画感、单一观点、少量或无标题字、保留横向留白；“X 配图”默认按此处理。 |
| X | 长文封面 / Article cover | 5:2，1500×600 | 横向编辑封面；一个主题焦点，标题与角色分区，关键内容避开裁切边缘。 |
| X | 个人主页横幅 / Header | 3:1，1500×500 | 超宽横幅，角色靠一侧，重要信息放在中间安全区；不要把普通 16:9 配图直接压扁。 |
| 公众号 | 文章主封面 | 约 2.35:1，900×383 | 横向封面，标题与豚豚主体错开；关键内容避开边缘，适配列表缩略裁切。 |
| 公众号 | 次条封面 | 1:1，500×500 | 方形主体构图，缩小后仍能识别角色与核心物件。 |
| 公众号 | 正文插图 | 16:9，1600×900；内容需要时可改 4:3 | 克制、清晰、适合嵌入文章；不套封面式大标题和营销海报结构。 |
| 任一平台 | 头像 / 贴纸 | 1:1，800×800 | 主体居中，缩小时保留脸和胸前徽章；周边留安全区。 |

### 平台风格规则

- **固定底层风格**：豚豚身份与毛毡短绒 3D 不变；柔和、清爽、轻微怪诞、留白；不套幼稚贴纸、通用广告模板或 PPT 模板。
- **平台只改变表达包装**：按阅读场景调整画幅、构图重心、标题空间、文字密度、视觉对比和安全区，不重设计角色。
- **小红书**：封面在缩略图里有明确主题和视觉焦点；如果需要标题，短而醒目。正文轮播页保持同一套网格和页边距。
- **抖音**：视频封面适配竖屏和界面遮挡安全区；以一个强动作和一个视觉焦点为主，避免把关键徽章或标题贴边。
- **X**：信息流插图优先表达一个观点或隐喻，文字少、横向关系清楚；长文封面使用 5:2；主页 Header 使用 3:1 横幅构图和中心安全区。
- **公众号**：主封面优先保证列表裁切后仍能读到主题；正文图保持编辑插画感和阅读留白，不把正文图误做成文章头图。
- 中文标题与简短说明直接纳入同一次生图提示词生成；标题用得意黑风格、说明用思源黑体风格。不要先生成无字底图再另行排字；不把大段正文塞进图里。若文字生成错误，重生成整张图。

### 选择与裁切规则

1. 用户给了具体尺寸时，以具体尺寸为准；先预告尺寸，再按其尺寸构图。
2. 只有平台名时，按表格里该平台最常见发布位置选默认值，并在出图前说清假设：小红书按笔记封面，抖音按视频封面，X 按信息流配图，公众号按正文插图；上下文有文章标题、视频脚本、主页等线索时优先采用上下文。
3. 同一主题发多个平台时，为各平台分别安排安全区和主体位置；需要复用同一画面时做裁切适配，不拉伸、不挤压角色，不裁掉脸或徽章。
4. 生图工具不支持目标画幅时，选最接近的受支持比例并在外部留足扩展/裁切空间；交付前读取输出文件的实际像素并核对比例；如尚未完成裁切或扩图，注明实际尺寸及待完成项，不能把目标尺寸当作已交付尺寸。

## avatar（默认 1:1）

- `head-closeup`：头肩特写，角色占画面 70%+，纯色背景。默认首选。
- `upper-half`：半身，露出 φ 标，适合需要品牌识别的头像。
- `wave`：半身挥手，更活泼。

## banner

- X 长文封面：使用 5:2，默认 1500×600；与长文正文插图、主页 Header 分开判断。
- X 信息流插图：使用 16:9，`side-mascot` 可给文案留横向空间。
- X 主页 Header：使用 3:1，角色偏左或偏右，头像覆盖区域与移动端裁切区域保持安全；不要用 16:9 代替。
- `walkthrough`：角色走在简化的校园/社群路径隐喻里。
- `tool-desk`：角色在桌前用电脑，暗示 AI / 内容创作。

## cover（未指定平台时默认 3:4，可按内容选 1:1）

- `hero-center`：角色居中 + 短标题。
- `metaphor-prop`：角色拿一个主题道具（漏斗、卡片、喇叭），标题少而大。
- `before-after`：左右对比只在用户明确要求时用。

## scene（未指定平台与用途时默认 1:1）

- `hold-object`：角色抱着主题物。
- `team-vibe`：角色加油/鼓掌。
- `thinking`：托腮或看屏幕。

## sticker（1:1）

- `expression-pack`：白底或透明感纯色底，单一表情，边缘干净，方便做表情包。

## 推荐启发式

- 只要「头像」→ `head-closeup` + 配色表中的柔和纯色背景。
- 只要「背景图/Banner」→ `side-mascot`。
- 讲 AI / 改造生意 → `tool-desk` 或抱笔记本。
- 讲流量 / 地推 / 社群 → `metaphor-prop`（喇叭或卡片）。
