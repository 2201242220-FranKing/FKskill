# 豚豚插画构图与隐喻规则

## 工作顺序

1. 从文章中找一个认知锚点：判断、断点、输入输出、分流、前后变化、承接路径或常见坑。
2. 把抽象概念转换成一个物理动作：卡住、漏掉、变重、分拣、沉淀、开门、回流、搭桥。
3. 选择一个低科技物件：纸箱、抽屉、漏斗、秤、门、井、梯子、水管、线团、闸门、怪工位。
4. 让豚豚承担动作：推、拉、扛、接、修、守、分拣或运送。
5. 用毛绒 3D 场景表达结构，避免把画面做成 PPT 或流程图。

## 可用结构

- **前后对比**：左侧混乱，右侧稳定，豚豚负责推动变化。
- **单物件隐喻**：一个箱子、门、机器或漏斗承载一个核心意思。
- **路线承接**：豚豚把信息、内容或用户从一个节点送到另一个节点。
- **角色状态**：豚豚在卡住、观察、修补、突破的连续状态中表达问题。
- **小场景分镜**：最多 3 个场景，表达失败到解决。
- **信息分拣**：豚豚把混杂信息分到 2–4 个不同出口。

## 反复刻规则

不要反复使用同一个箱子、传送带、漏斗或“豚豚举牌”构图。保留观点，替换物件、动作和空间关系。

## 画面约束

- 一张图只表达一个核心结构。
- 场景主体占画面约 40%–60%，保留安静留白。
- 文字只保留必要标签，默认不超过 5–8 处。
- 不在左上角写“流程图”“系统架构图”“常见坑”等类型标题。
