# 输入字段

这个 skill 默认优先读取下面 6 个字段。

## 必填优先级

1. 自我介绍
2. 性格关键词
3. 专业
4. 年级
5. 性别
6. 意向图 / 参考图

## 可补充字段

- 使用场景：头像 / 立绘 / 贴纸 / 主页卡片 / 活动海报
- 输出比例：1:1 / 3:4 / 4:5 / 16:9
- 风格偏向：软萌 / 清爽 / 轻科技 / 更校园 / 更活泼
- 必须保留：颜色、配件、气质、动作
- 必须避免：官方感、拟真感、幼态感、杂乱感

## 默认补问顺序

如果信息不全，先补这 4 项：

1. 这只宠物主要给谁看
2. 主要用在哪个页面
3. 想更像海洋感还是校园感
4. 有没有必须保留的颜色或配件

## MVP 对齐规则

单宠物 MVP 的输入字段与项目需求一致：

- 自我介绍
- 性格关键词
- 专业
- 年级
- 性别
- 意向图 / 参考图

其中意向图只提取视觉情绪和风格，不做人脸识别。
